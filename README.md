# JENNIERATION

Portfolio of Jennifer Kapend Fund: UX/UI, art and XR.

## Pages

- `index.html` is the full portfolio on one long page (Home, Projects, Jennie.ration, About me)
- `Main.dc.html`, `Projects.dc.html`, `Jennieration.dc.html`, `About.dc.html` are the same pages on their own
- `assets/` holds all images, videos and fonts
- `collage/assets/` holds the face pieces for the Jennie.ration collage
- `support.js` is the runtime that renders the pages

## Running it locally

The pages load each other, so open them through a small local server rather than double-clicking the file:

```
python3 -m http.server
```

Then go to http://localhost:8000.
